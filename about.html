Technical How-To's

Detailed step-by-step documentation on how TagaDetect operates under the hood

1. Predictive Token Shuffling & Cadence

Step 1: Sentence Tokenization — Raw text is parsed into discrete clause tokens while retaining boundary delimiters.
Step 2: Shuffled Heuristic Analysis — Evaluates n-gram uniformity and structural variance across the text blocks.
Step 3: Cadence Scoring — Computes perplexity invariants (0-100) and burstiness variability (sentence length distribution).
Step 4: Color-Coded Tagging — Sentences are tagged as High AI (rose/purple), Hybrid/Mixed (amber), or Authentic Human (emerald).

2. Automated Review upon Student Submission

Step 1: Student Passes Text — The student inputs their written reflection or essay into the submission portal.
Step 2: Instant Engine Execution — The submission triggers `generateSubmissionReview()` immediately on pass.
Step 3: Shared Report Storage — A comprehensive diagnostic report is attached to the submission record.
Step 4: Dual Transparency — Both the student and instructor view the identical analysis report before grading.

Frequently Asked Questions

Everything you need to know about permissions, detection accuracy, and roles

Can professors join classes as students?

No. In TagaDetect, role boundaries are strictly enforced. Only students can join classes using class codes. Professors create classes, publish activities, upload materials, and grade student submissions.

Why do professor accounts require admin approval?

To preserve institutional trust and curriculum integrity, newly registered professor accounts are placed in the Admin Verification Queue. An administrator confirms their faculty credentials before course creation is enabled.

How does the User Feedback mechanism work?

Users can submit feedback directly from the AI Detector results panel to flag false positives or report accuracy ratings. These reports stream to the administrator dashboard to continuously refine the machine learning heuristics.
